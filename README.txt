EMPLOYEES DATA TRACKER — FREE GITHUB PAGES VERSION

PUBLISHING
1. Create a PUBLIC GitHub repository named employees-data-tracker.
2. On the repository page choose Add file > Upload files.
3. Upload index.html and this README.txt directly to the repository root (not a nested folder).
4. Click Commit changes.
5. Open Settings > Pages. Under Build and deployment choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes; GitHub will show the website URL on the Pages settings page.

USAGE AND DATA
- This version contains NO employee records or sample personal data.
- Upload an Excel/CSV file in the website to view its dashboard, or enter data manually.
- Files are processed in the browser. The website does not send the uploaded file to a server.
- Entries and uploads do NOT sync between devices. Upload the same file separately on each device. Export/download a copy to keep changes.
- Anyone can open this public site; do not publish confidential employee information in the repository itself.
- Internet access is needed for chart/spreadsheet libraries loaded from public CDNs.
